# 🧠 Aplikasi Pembelajaran Interaktif: Berpikir Komputasional (Kelas 7)

Aplikasi web interaktif ini dirancang khusus untuk mendukung kegiatan belajar mengajar **Informatika Kelas VII** pada **Bab 1: Berpikir Komputasional untuk Penyelesaian Masalah**.

 dipicu dan disesuaikan dengan panduan **Buku Saku Informatika Kelas VII (BS_INFORMATIKA_VII)**.

## 🚀 Fitur Utama Website

1. **Rangkuman Materi Terstruktur**:
   - Pengertian & Tujuan Berpikir Komputasional.
   - 4 Fondasi Utama (*Dekomposisi, Pengenalan Pola, Abstraksi, Algoritma*).
   - Istilah Penting (*Efektif, Efisien, Struktur Data, Representasi Data*).
   - Dasar Pemrograman & Pengenalan **Scratch**.
2. **Laboratorium & Simulasi Interaktif**:
   - 🧩 **Lab 1 (Dekomposisi)**: Simulasi memecah tugas Pentas Seni Sekolah ke divisi-divisi pendukung.
   - 🍜 **Lab 2 (Algoritma Mi Instan)**: Mini-game menyusun langkah-langkah pembuatan mi secara berurutan.
   - 🎯 **Lab 3 (Abstraksi Alamat)**: Filter informasi penting untuk pengiriman paket.
   - 🐱 **Lab 4 (Scratch Code Simulator)**: Visualisasi jalannya blok kode Scratch pada Sprite Kucing.
3. **Kuis Interaktif & Selebrasi**:
   - Pertanyaan Pilihan Ganda dengan pengecekan jawaban *real-time*.
   - Animasi *Confetti* saat siswa meraih nilai tinggi.
4. **Desain Modern & Responsif**:
   - Fitur **Dark Mode / Light Mode**.
   - Ringan, cepat, dan nyaman diakses melalui *smartphone* maupun laptop.
